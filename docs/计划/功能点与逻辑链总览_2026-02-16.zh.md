# 功能点与逻辑链总览（发布前基线）

更新时间：2026-02-16  
适用范围：`prompthelper-bridge`（`webui` / `server` / `electron` / `ps-plugin-uxp-starter`）

## 1. 目标

1. 统一列出当前所有可见功能点。
2. 明确每个功能点的输入、输出、依赖与关键链路。
3. 作为全局规范审查与闭环审查的基线清单。

## 2. 功能分组与链路

### A. 窗口与壳层（Electron）

1. 主窗口显示/隐藏/最小化/置顶。
2. 右侧悬浮窗（浮层按钮）显示、拖拽、定位同步。
3. 插件桥接端口应用与进程侧同步。

关键链路：
`webui 交互 -> preload ipc -> electron/main.js -> BrowserWindow 状态变更`

### B. 对话与消息链路（Chat）

1. 新建对话、会话切换、会话持久化加载。
2. 用户消息发送、等待中止、消息编辑、重试分支。
3. AI 返回渲染（正文/JSON 提示词/思考流）。
4. 对话自动命名（可开关）。

关键链路：
`输入框 -> submitChatTurn -> 服务商请求 -> 解析响应 -> 消息入列 -> 持久化`

### C. 跑图链路（Image）

1. 基于 JSON 提示词跑图。
2. 基于上传区图片跑图（队列/中止/策略）。
3. 多图请求策略（自动/单发/多发）。
4. 服务商兼容格式切换（OpenAI/Google）。

关键链路：
`JSON/上传图 -> build request -> image API -> 结果图缓存/预览 -> 回传按钮`

### D. 上传与图片管理

1. 上传区图片添加（本地/PS 选区/PS 全图）。
2. 上传区排序拖拽与顺序持久化。
3. 上传尺寸/上传品质/格式控制（png/jpg）。
4. 最大数量、超限提醒、说明提示。

关键链路：
`图片输入 -> 压缩与格式化 -> 槽位列表 -> 可用于聊天/跑图`

### E. 预览区

1. 三种预览模式（全图/居中/缩略图）。
2. 图片序号与切换（按钮 + 区域点击）。
3. 悬浮显示切换控件。
4. 预览缓存与内存驻留控制（含缩略图预算）。

关键链路：
`跑图返回 -> 预览缓存写入 -> 模式按需加载 -> 用户切换显示`

### F. PS 插件桥接

1. 插件心跳与连接状态。
2. 选区抓图、全图抓图。
3. 回传图片到文档（文档/选区/尺寸对齐）。
4. 异常上报与修复指引。

关键链路：
`webui 请求 -> electron server queue -> UXP plugin 执行 -> bridge 返回 -> webui 消费`

### G. 预设系统

1. 对话预设（增删改、置顶、批量、导入导出）。
2. 指令预设（增删改、置顶、批量、导入导出）。
3. 身份预设（增删改、置顶、批量、导入导出，作用于聊天链路）。

关键链路：
`预设面板 -> 本地存储 -> 对话/跑图请求拼装`

### H. 设置系统

1. 对话 API 配置（地址/模型/Key/兼容格式）。
2. 生图 API 配置（地址/模型/Key/兼容格式/超时）。
3. 对话辅助功能（自动命名/思考翻译）。
4. 界面与悬浮窗（缩放、透明度、悬浮开关）。
5. 插件端口配置。

关键链路：
`设置变更 -> 本地 settings 持久化 -> 运行时重建配置与探测`

### I. 控制台系统

1. 大控制台（包装日志、修复指引、折叠去重、导出）。
2. 微型控制台（状态摘要）。
3. 日志导出（raw/wrapped）。

关键链路：
`业务事件 -> appendTraceLog/appendLog -> 包装展示 -> 导出`

## 3. 审查检查点（按功能逐项）

1. 输入合法性：空值/超限/非法格式/并发冲突。
2. 状态闭环：开始态 -> 进行态 -> 结果态（成功/失败/中止）。
3. 持久化闭环：写入成功、读取一致、异常可恢复。
4. UI 闭环：可达、可见、可收起、可回收、不卡顿。
5. 错误闭环：错误可见、修复指引正确、不会误导。
6. 性能闭环：对象可释放、缓存可淘汰、不会无上限增长。

## 4. 本轮审查输出要求

1. 每个功能点需给出“链路是否闭环”结论。
2. 发现问题必须给出“定位文件 + 修复动作”。
3. 修复前创建 Git 快照。
4. 修复后给出构建验证结果。
