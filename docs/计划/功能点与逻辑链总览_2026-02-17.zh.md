# 功能点与逻辑链总览（2026-02-17）

适用范围：`prompthelper-bridge-recovered-ce8k`

## 1. 目标

1. 汇总当前可用功能点。
2. 明确每个功能点的输入 -> 处理 -> 输出 -> 异常闭环。
3. 作为后续打包前总验收基线。

## 2. 功能闭环清单

### A. 壳层与窗口（Electron）

1. 输入：主面板与悬浮窗交互（置顶、最小化、透明度、显示/隐藏）。
2. 处理：`webui -> preload -> ipcMain.handle -> BrowserWindow`。
3. 输出：窗口尺寸、位置、显隐状态同步。
4. 异常闭环：主窗口不存在时返回 `ok: false`，不崩进程。

结论：闭环通过。

### B. 插件桥接与连接状态

1. 输入：插件心跳与桥接请求（`/ps/heartbeat`、`/ps/*`）。
2. 处理：bridge 服务维护 `psLastSeenAt` 与状态快照。
3. 输出：`/status` 返回 `psConnected`、`queueSize`、`psPluginLogLatestId`。
4. 异常闭环：网络/接口异常时，UI 回退到“插件待连接”并给修复指引。

本轮修复：`/ps/logs` 不再刷新心跳，避免“未开 PS 假在线”。

结论：闭环通过（已修复误判链路）。

### C. 对话链路（Chat）

1. 输入：用户文本、可选图片、多轮上下文。
2. 处理：配置校验 -> 组包 -> 调用聊天 API -> 写入会话持久化。
3. 输出：assistant 文本、可选 JSON 提示词、控制台日志。
4. 异常闭环：超时/中止/服务错误均回写状态并提示。

结论：闭环通过。

### D. 跑图与预览链路

1. 输入：JSON 提示词、上传区图片、服务商配置。
2. 处理：请求组装 -> API 调用 -> 结果缓存 -> 预览渲染。
3. 输出：多图预览、索引切换、导出与回传入口。
4. 异常闭环：失败日志进入大控制台并附修复指引。

结论：闭环通过。

### E. 上传区与缓存链路

1. 输入：本地文件、PS 选区/全图、拖拽粘贴。
2. 处理：编码压缩 -> 缓存落盘 -> 槽位维护与顺序调整。
3. 输出：上传槽位可视化、可用于聊天/跑图。
4. 异常闭环：超限、空文件、读取失败可见并可恢复。

结论：闭环通过。

### F. 日志与导出链路

1. 输入：渲染层日志、主进程日志、dev stdout/stderr。
2. 处理：格式归一化 -> 文本裁剪 -> 单文件导出。
3. 输出：可上报日志文件。
4. 异常闭环：导出取消/失败有明确返回。

本轮优化：dev 日志去 ANSI + 尾部 320 行摘要 + 导出头增强。

结论：闭环通过。

### G. 图标与资源链路

1. 输入：`webui/src/ce8k/icons/*.svg`。
2. 处理：构建时按引用打包。
3. 输出：主界面与悬浮窗图标渲染。
4. 异常闭环：缺失文件会在构建或运行期显式报错。

结论：闭环通过（引用与实体一致）。

## 3. 当前风险与后续

1. `webui` 当前为逆向恢复主入口（bundle 单文件），可运行但可维护性一般。
2. 若后续做组件化拆分，应以“可运行回归 + 每步可回滚”为前提分批进行。
3. 文档中的旧路径说明（历史 `App.jsx` 结构）仍有存量，属于文档一致性问题，不影响运行。
