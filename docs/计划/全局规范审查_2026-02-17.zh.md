# 全局规范审查（2026-02-17）

审查范围：`prompthelper-bridge-recovered-ce8k`（`webui` / `electron` / `server` / `scripts`）

## 1. 审查方法

1. 语法一致性：`node --check` 扫描源码（排除 `node_modules` 与恢复备份目录）。
2. 关键链路一致性：`preload` 的 `ipcRenderer.invoke` 与 `main` 的 `ipcMain.handle` 一致性比对。
3. 日志链路审查：控制台文档、主进程导出、dev 日志样本对齐。
4. 残留与目录审查：`.bak`、临时目录、计划文档目录归档检查。

## 2. 发现与处理

### F-01（已修复）

问题：插件连接状态存在“假在线”风险。  
定位：`server/index.js`、`electron/server/index.js` 的 `GET /ps/logs`。  
原因：该接口被 webui 轮询读取日志，但同时调用了 `markPsSeen()`，会错误刷新插件心跳。  
影响：未打开 PS 时，状态仍可能显示“插件连接中”。  
修复：移除 `/ps/logs` 中 `markPsSeen()` 调用，并补充注释说明。

### F-02（已修复）

问题：导出日志中的 dev 段可读性差。  
定位：`electron/main.js`。  
原因：Vite 日志包含 ANSI 控制符，且历史行过长。  
修复：

1. 新增 ANSI 清洗函数。
2. 新增 dev 日志尾部摘要（保留最近 320 行，标记省略数量）。
3. 导出头增加版本与计数字段。

### F-03（已确认）

问题：IPC 调用可能存在“前端调用但主进程无处理器”风险。  
结果：`invoke=45`，`handle=45`，差集为空，链路一致。

### F-04（已确认）

问题：图标引用可能有缺失或临时目录残留。  
结果：

1. `webui/src/ce8k/icons` 引用/实体一致。
2. 活跃源码树中不存在 `icons.__semantic_tmp__`。
3. 备份图标已归档在 `docs/recovery/worktree-backups/`。
