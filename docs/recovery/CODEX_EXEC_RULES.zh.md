# Codex 执行规则（当前仓库）

更新时间：2026-02-17

## 1. 编码规则（强制）

1. 读取文本必须显式 UTF-8（命令行读取带 `-Encoding utf8`）。
2. 写入文本必须显式 UTF-8。
3. 未确认编码前，禁止整文件替换。
4. 出现乱码风险时：先备份 -> 再恢复基线 -> 再修改。

## 2. 备份规则（强制）

1. 每个修复批次前先做 Git 备份点（tag 或 commit）。
2. 若 Git 备份因权限受阻，先说明用途并请求权限。
3. 若 Git 备份暂不可用，先做文件级备份到 `docs/recovery/worktree-backups/<timestamp>/`。

## 3. 修改规则

1. 不做未经确认的替代路径。
2. 不为了拆分而拆分；仅在可读性/维护性显著提升时拆分或整合。
3. 清理操作优先归档迁移，不做破坏性删除。
4. 每阶段输出可核查结果（文件、校验、差异）。

## 4. 本轮计划执行规则

1. 先完成日志专项，再做全局规范审查。
2. 审查发现问题：直接排计划并修复，不等待额外决策。
3. `server/index.js` 当前以备份基线为准，后续修改前必须先备份。
4. 图标与计划目录整理保持“功能完整优先”。
